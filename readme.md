# mds-ts-piscine

## Setup and Installation

1/ **Clone the repository:**

````sh
git clone https://github.com/alexishadjian/mds-ts-piscine
````

````sh
cd mds-ts-piscine
````

2/ **Install dependencies:**

````sh
npm install
````

2/ **Running the project:**

```sh
npx tsc --watch
```

Start live server vscode extension
